# 🏙️ AcessCity

**Tecnologia, acessibilidade e inclusão urbana.**

## 📌 Sobre o projeto

O **AcessCity** é um projeto web voltado à acessibilidade urbana, desenvolvido com o objetivo de contribuir para a construção de cidades mais inclusivas. A plataforma busca facilitar o registro e o acompanhamento de problemas de acessibilidade, promovendo a conscientização sobre as dificuldades encontradas nos espaços urbanos.

O projeto também apresenta recursos como mapa de ocorrências, denúncias e recompensas, relacionados à proposta de incentivar a participação das pessoas na identificação de barreiras urbanas.

## 🎯 Objetivos

- Promover a conscientização sobre a acessibilidade urbana.
- Facilitar o registro e a visualização de problemas de acessibilidade.
- Incentivar a participação da comunidade.
- Utilizar a tecnologia para contribuir com cidades mais inclusivas.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e organização visual.
- **JavaScript:** implementação de funcionalidades e interatividade.
- **GitHub:** armazenamento do código-fonte e controle de versões.
- **Vercel:** hospedagem e publicação do site na internet.

## ☁️ Hospedagem e deploy

O AcessCity utiliza a plataforma Vercel para hospedar e disponibilizar o site na internet.

A integração com o GitHub permite acompanhar as alterações no código e iniciar novas implantações quando são realizadas atualizações no repositório, conforme as configurações do projeto.

Após a conclusão do processo de implantação, o site atualizado pode ser acessado pela URL pública.

## 🔄 Integração e CI/CD

O projeto demonstra conceitos de integração e implantação contínuas por meio da conexão entre GitHub e Vercel.

- **Integração:** o GitHub armazena o código e mantém o histórico de alterações por meio de commits.
- **Automatização do deploy:** a integração configurada com a Vercel permite iniciar novas implantações após atualizações no repositório.
- **Acompanhamento:** o painel da Vercel permite verificar o status das implantações.

O fluxo utilizado pode ser representado da seguinte forma:

**Alteração no código → Commit no GitHub → Implantação na Vercel → Site atualizado**

Esse processo facilita a publicação de novas versões e reduz a necessidade de iniciar manualmente cada implantação.
